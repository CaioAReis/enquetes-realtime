# Sistema de Enquetes em Tempo Real
Um sistema full-stack de votação reativa que permite aos usuários criar enquetes customizadas e visualizar os votos computados em tempo real.

## Tecnologias Utilizadas
### Frontend
- Angular: Utilizando a arquitetura moderna de Standalone Components.
- Signals & RxJS: Gerenciamento de estado reativo e imutável.
- Tailwind CSS: Estilização utilitária para uma interface limpa e responsiva.
- SockJS & STOMP: Cliente WebSocket com fallback nativo.
### Backend
- Spring Boot: API RESTful e configuração de WebSockets.
- Spring Data JPA / Hibernate: Mapeamento objeto-relacional e gerenciamento de banco de dados.
- PostgreSQL: Banco de dados relacional
